
# Roshini Kumari P: Portfolio

A multi-page personal portfolio built with plain HTML, CSS and JavaScript (no frameworks).

**Live site:** https://roshinikumari015018.github.io/my-portfolio/

## Pages
| Page | What it has |
| --- | --- |
| `index.html` | Home: intro, "View Resume" and "Let's Talk" buttons |
| `about.html` | Background, highlights carousel, journey timeline, skills |
| `projects.html` | Project cards with hover overlays and tech tags |
| `resume.html` | Embedded PDF resume with a download button |
| `contact.html` | Contact details and a form with validation |

## Features
- Dark / light theme toggle, saved with `localStorage`
- Mobile-friendly navigation menu
- Carousel with arrows, dots, keyboard and swipe support
- Contact form with inline error messages and a success message
- Responsive layout for mobile, tablet and desktop

## Files
- `style.css`: theme colours, layout and responsive rules
- `script.js`: theme toggle, menu, carousel and form
- `resume.pdf`: the resume shown on the Resume page

## Run locally
Open `index.html` in a browser, or right-click it in VS Code and choose **Open with Live Server**.

## Deploy
Push to GitHub, then go to **Settings → Pages**, choose branch `main` and folder `/ (root)`, and save.

## Customise
- Colours: edit the variables at the top of `style.css`.
- Resume: replace `resume.pdf` with a new file of the same name.
- Project links: update the "View on GitHub" links in `projects.html`.
